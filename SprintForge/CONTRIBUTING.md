# Contribuindo com o SprintForge

Obrigado pelo interesse em contribuir com o SprintForge!

O projeto reúne práticas de desenvolvimento ágil, incluindo Scrum, Kanban e Extreme Programming (XP).

## Fluxo de contribuição

1. Crie uma branch a partir da versão atualizada da `main`.
2. Realize uma alteração pequena e com objetivo bem definido.
3. Revise as modificações antes de criar o commit.
4. Execute as validações aplicáveis ao projeto.
5. Abra um Pull Request descrevendo a alteração realizada.

## Convenções de commits

Utilize mensagens claras e objetivas, preferencialmente seguindo estas categorias:

- `feat:` novas funcionalidades.
- `fix:` correções de problemas.
- `docs:` alterações na documentação.
- `refactor:` melhorias internas sem alteração intencional de comportamento.
- `test:` criação ou atualização de testes.

## Boas práticas

- Evite misturar alterações sem relação no mesmo Pull Request.
- Preserve as funcionalidades existentes.
- Não inclua credenciais ou informações sensíveis.
- Documente mudanças relevantes.
- Mantenha a comunicação respeitosa e construtiva.

## Revisão

Antes de enviar sua contribuição, verifique se as alterações estão restritas ao objetivo proposto e se não existem arquivos adicionados acidentalmente.
